# Small Office Network (Cisco Packet Tracer)

Simulation eines kleinen Firmennetzwerks in Cisco Packet Tracer mit DHCP-Server, IP-Routing und einem Webserver.

## Netzwerk-Details
- Router Gateway: 192.168.1.30
- DHCP Range: 192.168.1.0/24 (Exkludiert: .30)
- Webserver: 192.168.1.10 (HTTP Service)
- DNS: 8.8.8.8
